  • ▪️ Each row can have a unique index label.
  • ▪️ Indexing helps retrieve particular rows quickly.
  • ▪️ It is useful for selecting and aligning data.
  • ▪️ Labels can be accessed using methods such as .loc[].

MISSING DATA IN PANDAS

Pandas represents missing numeric values using NaN and does not automatically remove or replace them.

  • ▪️ Missing values are commonly represented as NaN.
  • ▪️ Many Pandas calculations skip missing values by default.
  • ▪️ isna() and isnull() can identify missing values.
  • ▪️ dropna() and fillna() can handle them.

DATA AGGREGATION

Data aggregation is the process of combining multiple values into a summary value such as sum, mean or count.

  • ▪️ Aggregation converts detailed data into useful summaries.
  • ▪️ Common functions include sum(), mean() and count().
  • ▪️ It is commonly used with groupby().
💻 EXAMPLE PROGRAM 
import pandas as pd

df = pd.DataFrame({
    "Dept": ["IT", "IT", "HR"],
    "Salary": [50000, 60000, 55000]
})

print(df.groupby("Dept")["Salary"].mean())
📤 OUTPUT 
Dept
HR    55000.0
IT    55000.0
Name: Salary, dtype: float64

1. Write a Python code to create a DataFrame and demonstrate the use of .loc[] and .iloc[] for accessing data.

.loc[]

.loc[] is used for label-based selection. It accesses rows and columns using their labels.

  • ▪️ Selects data using row and column labels.
  • ▪️ Useful when meaningful index labels are available.

Syntax:

df.loc[row_label, column_label]
💻 EXAMPLE PROGRAM 
import pandas as pd

df = pd.DataFrame({
    "Employee_Name": ["Arun", "Bala", "Charan"],
    "Salary": [55000, 48000, 62000]
})

print(df.loc[1, "Employee_Name"])
📤 OUTPUT 
Bala

.iloc[]

.iloc[] is used for integer-position-based selection. It accesses rows and columns according to their numerical positions.

  • ▪️ Uses integer positions beginning from 0.
  • ▪️ Useful when exact row or column positions are known.

Syntax:

df.iloc[row_position, column_position]
💻 EXAMPLE PROGRAM 
import pandas as pd

df = pd.DataFrame({
    "Employee_Name": ["Arun", "Bala", "Charan"],
    "Salary": [55000, 48000, 62000]
})

print(df.iloc[2, 0])
📤 OUTPUT 
Charan

COMBINING AND MERGING DATASETS

Combining and merging are Pandas techniques used to bring data from different DataFrames into a single useful dataset. They are especially useful when related information is stored separately.

  • ▪️ merge(): Combines DataFrames using a common column or key, similar to a database join.
  • ▪️ concat(): Combines DataFrames by stacking rows or columns.

ADVANTAGES:

Advantage Explanation
Data Integration Combines related information from multiple datasets into one dataset.
Less Manual Work Common keys can be matched automatically instead of matching records manually.
Better Analysis More complete data allows better comparison and decision-making.
Flexible Different types of joins and concatenation methods can be selected according to the requirement.

SYNTAX:

pd.merge(df1, df2, on="Common_Column")

pd.concat([df1, df2], ignore_index=True)
💻 EXAMPLE PROGRAM 
import pandas as pd

# Employee details

employees = pd.DataFrame({
"Employee_ID": [101, 102, 103],
"Name": ["Arun", "Bala", "Charan"],
"Department": ["IT", "HR", "Finance"]
})

# Employee salary details

salary = pd.DataFrame({
"Employee_ID": [101, 102, 103],
"Salary": [55000, 48000, 60000]
})

# Merge both datasets using Employee_ID

result = pd.merge(
employees,
salary,
on="Employee_ID"
)

print(result)

1          102    Bala         HR   48000

dropna()

dropna() removes rows or columns containing missing values.

  • ▪️ Useful when incomplete records are not required.
  • ▪️ It can remove rows containing NaN.

Syntax:

df.dropna()

df = pd.DataFrame({
    "Name": ["Arun", "Bala"],
    "Marks": [85, None]
})

fillna()

fillna() replaces missing values with a specified value such as zero, mean or another suitable value.

  • ▪️ Preserves the existing rows.
  • ▪️ Useful when missing records should not be deleted.

Syntax:

    df["Marks"].mean()
)

print(df)
📤 OUTPUT

0  Arun   85.0

GROUPED AGGREGATION

Aggregation is the process of summarizing grouped data into a single value. When combined with groupby(), it calculates summary statistics for each group separately. groupby() divides DataFrame into groups based on a column and aggregation applies function on each group.

  • ▪️ Grouping - groupby() divides DataFrame into groups based on a column.
  • ▪️ Aggregation - Applies a function on each group to get summary.

    • AGGREGATION FUNCTIONS

  • ▪️ sum() - Calculates total of all values in each group.
  • ▪️ mean() - Calculates average value of each group.
  • ▪️ count() - Counts number of non-missing values in each group.
  • ▪️ agg() - Applies multiple aggregation functions together at once efficiently.

SYNTAX:

df.groupby("group_column")["value_column"].sum()

df.groupby("group_column")["value_column"].mean()

df.groupby("group_column")["value_column"].count()

df.groupby("group_column")["value_column"].agg(["sum", "mean", "count"])
💻 EXAMPLE PROGRAM 
import pandas as pd

df = pd.DataFrame({
    "Department": ["IT", "IT", "HR", "HR"],
    "Salary": [50000, 60000, 55000, 65000]
})

print("Sum:")
print(df.groupby("Department")["Salary"].sum())

print("\nMean:")
print(df.groupby("Department")["Salary"].mean())

print("\nCount:")
print(df.groupby("Department")["Salary"].count())

print("\nAll using agg():")
result = df.groupby("Department")["Salary"].agg(["sum", "mean", "count"])
print(result)

2. A company stores employee data (ID, Name, Department, Salary). Write a program to: Remove duplicate rows, Replace missing salary with department's average, Aggregate salaries by department, Discuss how transformations help in data cleaning.
10 MARKS

💻 CODE

🐼 EMPLOYEE DATA CLEANING PROGRAM 
import pandas as pd

# Step 1: Create employee data
df = pd.DataFrame({
    "ID": [101, 102, 102, 103, 104],
    "Name": ["Arun", "Bala", "Bala", "Divya", "Esha"],
    "Department": ["IT", "HR", "HR", "IT", "HR"],
    "Salary": [50000, None, None, 60000, 55000]
})

# Step 2: Remove duplicate rows
df = df.drop_duplicates()

# Step 3: Calculate department-wise salary average
dept_avg = df.groupby(
    "Department"
)["Salary"].transform("mean")

# Step 4: Fill missing salary using department average
df["Salary"] = df["Salary"].fillna(dept_avg)

# Step 5: Aggregate salary by department
summary = df.groupby(
    "Department"
)["Salary"].agg(["count", "sum", "mean"])

# Step 6: Display cleaned data
print(df)

# Step 7: Display department summary
print("\nDepartment-wise Salary Summary:")
print(summary)

            count       sum     mean
Department
HR              2  110000.0  55000.0
IT              2  110000.0  55000.0

📚 Concept Explanation

  • ▪️ drop_duplicates(): removes repeated employee records.
  • ▪️ groupby(): divides employees according to department.
  • ▪️ transform("mean"): calculates the average salary for each employee's department.
  • ▪️ fillna(): replaces missing salary values with the appropriate department average.
  • ▪️ agg(): generates count, total and average salary.

Data transformations improve data quality by removing duplicate records, filling missing information with meaningful values and producing summarized data. This makes the employee dataset cleaner and easier to analyze.

3. Evaluate different strategies of handling missing time series data (forward fill, backward fill, interpolation). Provide examples.

import pandas as pd

dates = pd.date_range(

📚 Concept Explanation

Forward fill is suitable when the previous observation should continue until a new value appears. Backward fill is useful when the next observation is a better representation. Interpolation is useful when values are expected to change gradually over time.

In the program, the original series contains two missing values. All three techniques are applied and compared. Interpolation produces 120 and 160 because the values change evenly between the known observations.

🐼 STUDENTS AND MARKS MERGING PROGRAM 
import pandas as pd

# Step 1: Create Students dataset
students = pd.DataFrame({
    "Name": ["Arun", "Bala", "Charan", "Divya"],
    "Roll No": [101, 102, 103, 104],
    "Class": [
        "B.Sc DS",
        "B.Sc DS",
        "B.Sc DS",
        "B.Sc DS"
    ]
})

# Step 2: Create Marks dataset
marks = pd.DataFrame({
    "Roll No": [
        101, 102, 103, 104,
        101, 102, 103, 104
    ],
    "Subject": [
        "Python", "Python",
        "Python", "Python",
        "Statistics", "Statistics",
        "Statistics", "Statistics"
    ],
    "Marks": [
        85, 92, 78, 88,
        90, 86, 80, 84
    ]
})

# Step 3: Merge both datasets
result = pd.merge(
    students,
    marks,
    on="Roll No",
    how="inner",
    sort=False
)

# Step 4: Generate subject-wise average
subject_avg = result.groupby(
    "Subject"
)["Marks"].mean()

# Step 5: Display merged data
print("Merged Student Records:")
print(result)

# Step 6: Display average marks
print("\nSubject-wise Average Marks:")
print(subject_avg)

5. Design a small Pandas application that processes stock market time series data: Handle missing, Compute moving averages, Aggregate monthly performance, Generate summary report, Justify how Pandas simplifies time series analysis.

💻 CODE

🐼 STOCK MARKET TIME SERIES PROGRAM 
import pandas as pd

# Step 1: Create stock market dates
dates = pd.to_datetime([
    "2026-01-28",
    "2026-01-29",
    "2026-01-30",
    "2026-01-31",
    "2026-02-01",
    "2026-02-02",
    "2026-02-03",
    "2026-02-04",
    "2026-02-05",
    "2026-02-06"
])

# Step 2: Create stock prices
df = pd.DataFrame({
    "Price": [
        100, 102, None, 106, 108,
        None, 112, 110, 114, 116
    ]
}, index=dates)

# Step 3: Handle missing values
df["Price"] = df["Price"].interpolate()

# Step 4: Calculate 3-day moving average
df["Moving_Average"] = (
    df["Price"].rolling(3).mean()
)

# Step 5: Aggregate monthly performance
monthly = df["Price"].groupby(
    df.index.to_period("M")
).agg(["first", "last", "mean"])

# Step 6: Calculate monthly return
monthly["Return_%"] = (
    (monthly["last"] - monthly["first"])
    / monthly["first"] * 100
).round(2)

# Step 7: Rename columns
monthly.columns = [
    "Start_Price",
    "End_Price",
    "Average_Price",
    "Return_%"
]

# Step 8: Generate summary report
print("Cleaned Stock Data:")
print(
    df.to_string(
        float_format=lambda x: f"{x:.2f}"
    )
)

print("\nMonthly Performance:")
print(monthly.round(2))

print("\nSummary Report:")
print(
    f"Average Price: {df['Price'].mean():.2f}"
)
print(
    f"Highest Price: {df['Price'].max():.2f}"
)
print(
    f"Lowest Price: {df['Price'].min():.2f}"
)

📚 Concept Explanation

  • ▪️ Time Series: Stock prices are indexed using dates.
  • ▪️ Interpolation: Estimates the missing stock prices between known values.
  • ▪️ Moving Average: Calculates the average of recent observations to identify trends.

  • ▪️ agg(): Calculates monthly starting price, ending price and average price.
  • ▪️ Return: Measures the percentage change from the beginning to the end of a month.

Pandas simplifies stock market analysis because it provides date indexes, missing-value handling, rolling calculations and grouped aggregation in a compact form. Instead of manually processing every date, Pandas performs these operations directly on the time series.
