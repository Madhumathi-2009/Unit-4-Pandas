## About this repo

> A structured **Question Bank & Answer website** created for **B.Sc Data Science & AI — Students**.
>
> Practice important questions, view answers when needed, understand programs, check outputs, and prepare confidently. 🎯

---

## 📚 What's Included?

| 📝 Section | 📖 Focus |
|:---:|:---|
| 🟢 **2 Marks** | Short-answer concepts |
| 🟠 **5 Marks** | Theory + Programs + Outputs |
| 🔴 **10 Marks** | Program + Output + Concept Explanation |
| ⚡ **Bonus** | 18 Important Pandas Concepts |

---

## ✨ Features

- 🎯 **Exam-focused Question Bank**
- 👆 **Click to View Answers**
- 💻 **Programs with Explanations**
- 🖥️ **Expected Outputs**
- ⚡ **18-Concept Quick Revision Table**
- 🔎 **Easy Navigation & Search**
- 📱 **Clean & Interactive Web Design**
